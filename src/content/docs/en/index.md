Fita reads customer and supplier records from the systems you already have, finds the ones that describe the same entity and builds one [golden record](/en/concepts/golden-record/) per entity. Every value keeps the source it came from.

This site explains how to install Fita, configure it and run it every day.

Start with the concepts. The getting started guide with the demo comes next.
